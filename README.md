# 🫀 Heart Disease Classification: Custom $k$-NN vs. Scikit-Learn

A machine learning project implementing a **$k$-Nearest Neighbors ($k$-NN)** classifier from scratch using pure NumPy and comparing its mathematical correctness, performance, and workflow against Scikit-Learn baselines and hyperparameter-tuned pipelines.

---

## 📌 Project Overview

In medical diagnostics, machine learning models must prioritize **Recall (Sensitivity)** to minimize **False Negatives**—ensuring individuals with heart disease are accurately flagged for clinical follow-up.

This repository demonstrates:
1. **Custom NumPy Implementation:** Building $k$-NN from first principles using $L_2$ Euclidean distance matrix calculation and majority voting.
2. **Standardization & Leakage Prevention:** Applying `StandardScaler` and establishing fold-level transformation using Scikit-Learn `Pipeline` objects.
3. **Hyperparameter Optimization:** Tuning $k$ via `GridSearchCV` with cross-validation optimized specifically for **Recall**.
4. **Verification:** Proving that the custom mathematical implementation yields $100\%$ identical predictions to Scikit-Learn's optimized C-engine.

## 🧮 Custom $k$-NN Mathematics

The custom classifier measures proximity in feature space using $L_2$ Euclidean distance between test sample $x$ and training sample $x_i$:

$$d(x, x_i) = \sqrt{\sum_{j=1}^{p} (x_j - x_{i,j})^2}$$

### Algorithm Workflow
1. **Distance Calculation:** Compute $L_2$ distances from the query sample to all points in the training set.
2. **Neighbor Identification:** Sort distances in ascending order and select indices of top $k$ nearest neighbors.
3. **Class Voting:** Extract class labels of selected neighbors and return the majority class vote via `np.bincount()`.

Models were evaluated on a held-out test split ($20\%$). Hyperparameter search selected $k=15$ as the optimal neighbor count for maximizing Recall.

## 💡 Key Takeaways

* **Mathematical Verification:** The predictions generated by the custom NumPy $k$-NN class matched Scikit-Learn's implementation identically, verifying distance calculations and voting logic.
* **Clinical Metric Alignment:** By setting `scoring='recall'` in `GridSearchCV`, the model actively minimized False Negatives (missing patients with heart disease), which is vital in medical diagnostics.
* **Data Leakage Mitigation:** Utilizing Scikit-Learn `Pipeline` guarantees scaling parameters ($\mu, \sigma$) are derived solely from training folds during cross-validation.
